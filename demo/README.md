# 🎬 Demo Kit

Ready-made inputs for trying or demoing ResumeRank — four realistic sample
resumes (strong → weak matches) plus a matching job description.

## Use it
1. Open the app → paste `job_description.txt` into the JD box.
2. Upload all four files from `demo/resumes/` and pick **Batch Screening**.
3. Watch the rankings: Tunde (senior DE, strongest) should top the board,
   Fatima mid-high, Chiamaka mid, Ibrahim (frontend) at the bottom.

These are synthetic people — generated for demonstration.
